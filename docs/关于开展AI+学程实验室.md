# 关于开展AI+学程实验室
2026—2027学年项目申报工作的通知

为回应人工智能快速发展对教育提出的新课题，推动教师由技术工具使用者走向人机协同的学习设计者，学校“AI+学程实验室”，面向全校教师遴选首批实践项目。项目立足一线教师真实的工作与课堂问题，支持教师重构学习任务、反馈机制与评价方式，形成可验证、可复用的学程实践。现将有关事项通知如下：

# 一、申报对象与名额

全校在岗教师均可申报，鼓励跨学科、跨年级组协作。项目周期自立项之日起，至2027年5月15日止。每个项目含负责人在内不超过6人。每个立项项目发放项目经费3000元，立项后一次性拨付。

# 二、申报范围

项目应从学生成长和教育教学的真实问题出发，重点支持以下方向：

1. AI支持的课堂与学习创新：如模拟体验式学习、游戏化学习、项目式学习、思辨式学习等。

2. AI支持的学程设计与评价改进：如学习任务重构、形成性追问、过程性评价、学习证据采集与个性化反馈等。

3. AI支持的教师专业成长：如教学设计工作台、新手教师情境模拟、名师经验提炼与专业学习转化等。

4. AI支持的教师减负增效：如学生观察记录、备课资产库、专业阅读消化、一备多用等；须说明其如何最终服务于学生学习。

5. 其他内容：如关于学程的探索，学生自主学习能力的培养等。

# 三、申报与评审

请申报人填写《AI+学程实验室项目申报表》，并附研究方案（5000字以内，匿名评审版），于2026年9月18日17:00前将电子版发送至ailab@qdzx.net（邮件主题：AI+学程申报+姓名+项目名称）。学校将组织评审：2026年9月下旬完成形式审查，10月上旬组织专家评审，重点考察学习问题的真实具体性、学程设计质量、AI使用边界、实施可行性及成果的证据与复用价值。立项结果拟于2026年10月中旬通过校内通知公布。

# 四、经费与奖励

1.项目经费：每个立项项目发放项目经费3000元，立项后一次性支付给项目负责人。学校不再支付项目实施的其他费用。

2.结项奖励：项目结项后，学校组织评审，评选A等项目每个奖励5000元和B等项目每个奖励3000元，颁发证书并纳入学校“AI+学程”优秀项目库。学校根据相关规定，给予结项项目组老师学术积分。结项不合格者，不参与评奖，并取消下一年度申报资格。

3.项目管理：项目负责人应于2027年1月提交中期进展表；2027年5月15日前完成结项，结项成果形式不限（课例、教学资源包、研究报告、学生作品等任选其一或组合）。
